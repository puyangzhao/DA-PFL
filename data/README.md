# Data

Place the cleaned analytic file at `data/nhanes_cleaned.csv`.

Expected columns:

`RIAGENDR, RIDAGEYR, RIDRETH3, INDFMPIR, BMXBMI, BPXOSY1, BPXODI1, LBXGLU, LBXIN, SMQ020, ALQ111, PAD680, PAD820, diabetes`

The file used in the article has 1,119 rows and 83 diabetes-positive participants. The dataset is not committed to GitHub. NHANES source data are publicly available from CDC, but users should obtain and process them under the applicable CDC terms.
